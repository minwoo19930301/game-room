# 구름길 어드벤처

달리기, 점프, 블록과 아이템을 중심으로 만든 오리지널 횡스크롤 게임입니다. 패미컴 시절의 플랫폼 게임 조작을 기준으로 했으며, 공중에서 다시 뛰거나 날갯짓하는 기능은 없습니다. 초원, 지하 동굴, 성의 세 스테이지가 이어집니다.

- 플레이: `/platformer/`
- 무음 자동 플레이: `/platformer/?preview=1`
- 별도 빌드나 외부 라이브러리 없이 `public/`에서 실행됩니다.

## 조작

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 이동 | ← → / A D | ◀ ▶ |
| 점프 | Space / X / ↑ / W | A |
| 달리기 · 불꽃 발사 | Shift / Z | B |
| 웅크리기 | ↓ / S | ▼ |
| 일시정지 | P / Escape | 상단 Ⅱ |

점프를 짧게 누르면 낮게, 길게 누르면 높게 뜁니다. 달리면 더 멀리 뛰며, 방향을 바꿀 때 감속합니다. 적을 위에서 밟거나 등껍질을 차서 물리칠 수 있습니다. 성장, 불꽃, 무적 별, 추가 목숨 아이템이 있고 코인 100개를 모으면 목숨이 늘어납니다. 성장 상태에서 벽돌을 부술 수 있으며, 체크포인트 이후에 죽으면 그 지점에서 재개합니다. 마지막 성에서는 보스를 쓰러뜨려야 출구가 열립니다.

깃발에 닿으면 깃발 하강과 출구를 향해 걷는 연출 후 남은 시간이 점수에 더해집니다. 소리는 처음에 꺼져 있으며 상단 버튼으로 켤 수 있습니다. 게임 오버 뒤 다시 도전하면 해당 스테이지를 목숨 3개로 시작합니다.

## 구현

- `src/engine.mjs`: 순수 상태 엔진, 고정 시간 단계, 타일 충돌과 아이템·적·보스 규칙
- `src/levels.mjs`: 독립적인 세 스테이지 데이터
- `src/art.mjs`, `src/render.mjs`: 직접 구성한 픽셀 스프라이트와 배경, HUD
- `src/main.mjs`: 입력, 메뉴, 일시정지, 점수 저장, 미리보기
- `src/audio.mjs`: 짧은 Web Audio 합성 효과음

미리보기는 실제 엔진에 이동·점프 입력을 전달합니다. 일반 게임과 같은 규칙으로 실행되며 26초 또는 클리어 때 처음부터 반복합니다. 입력과 소리, 저장은 비활성화합니다. 첫 렌더 후 `data-preview-ready="true"`와 `game-preview-ready` 메시지를 한 번 보내 홈의 카드를 활성화합니다. 일반 플레이 최고 점수의 저장 키는 `cloudway-best`입니다.

## 검증

```sh
node --test public/platformer/tests/*.test.mjs
```

변동 프레임 간격, 점프 높이, 공중 재점프 방지, 점프 입력 버퍼, 바닥·벽·천장·발판 충돌, 성장과 웅크리기, 불꽃, 무적, 코인, 등껍질 연쇄 공격, 피해와 목숨, 체크포인트, 스테이지 상태 인계, 보스 출구 잠금과 클리어 연출을 검사합니다. 전체 플레이 검사는 첫 스테이지부터 마지막 보스와 출구까지 이동·점프·불꽃 입력만 사용합니다. 워프나 체력 변경 없이 연속 진행을 검증합니다.

브라우저에서 키보드 이동·점프·블록 타격, 터치 이동과 점프, 일시정지·재개, 모바일 크기, 자동 미리보기와 홈 카드 연결을 확인했습니다.

## 출처

엔진, 레벨, 픽셀 캐릭터와 효과음은 이 저장소를 위해 새로 작성했습니다. 네이비의 검은 머리·남색 재킷·흰 티셔츠를 픽셀 캐릭터에 반영했습니다. 조작 참고 자료는 [닌텐도의 공식 Super Mario Bros. 설명서](https://www.nintendo.co.jp/clv/manuals/en/pdf/CLV-P-NAAAE.pdf)입니다. 원작의 캐릭터 이미지, 음악, 코드나 스테이지 데이터는 포함하지 않습니다. Galmuri11 폰트는 기존 `../rangers/fonts/`의 파일과 라이선스를 공유합니다.
