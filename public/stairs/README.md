# 끝없는 계단

오르기와 방향 전환, 두 가지 조작으로 끝없는 지그재그 계단을 오르는 아케이드 게임입니다. 기존 네이비 재킷·흰 티셔츠 캐릭터 원화의 대기, 달리기, 점프, 실패 포즈를 사용합니다. 계단과 하늘은 Canvas 2D로 그리며 원본의 입체 면, 깊이, 점프와 착지 연출을 유지했습니다.

- 일반 플레이: `/stairs/`
- 홈의 자동 플레이: `/stairs/?preview=1`
- 바로 시작: `/stairs/?autostart=1`

## 조작과 규칙

| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 바라보는 방향으로 한 계단 오르기 | Space, ↑, W, X, Enter | 오른쪽 버튼 또는 화면 오른쪽 |
| 방향을 바꾸고 한 계단 오르기 | Shift, ←, →, A, D, Z | 왼쪽 버튼 또는 화면 왼쪽 |
| 다시 시작 | Space, Enter | 다시하기 버튼 |

계단이 없는 방향으로 발을 디디면 추락합니다. 상단의 제한시간 게이지는 계속 감소하며, 계단을 정확하게 오르면 회복됩니다. 점수가 높아질수록 시간이 더 빨리 줄어듭니다. 50계단마다 축하 효과가 나오고 하늘은 낮, 노을, 밤으로 바뀝니다. 최고 기록과 음소거 설정은 각각 `endless-stairs-best`, `endless-stairs-muted`에 저장합니다.

## 미리보기

`preview=1`에서는 CPU가 실제 다음 계단 방향을 읽어 동일한 `action()` 함수를 호출합니다. 점프, 방향 전환, 시간 감소, 점수 증가와 계단 생성 규칙은 일반 플레이와 같습니다. 120계단 또는 50초에 도달하면 처음부터 반복하고, 추락하면 짧은 동작 뒤 다시 시작합니다.

미리보기는 사용자 입력과 HUD를 숨기며 오디오를 생성하지 않고 기록·설정을 저장하지 않습니다. 16:9 카드의 전체 너비를 사용합니다. 캐릭터 원화를 불러와 실제 첫 프레임을 그린 뒤 아래 준비 신호를 한 번 전송합니다.

```js
document.documentElement.dataset.previewReady = 'true';
window.parent.postMessage({ type: 'game-preview-ready' }, location.origin);
```

## 원본과 라이선스

규칙과 기반 코드는 [flam-ing/flaming-games의 flamingo-stairs](https://github.com/flam-ing/flaming-games/tree/c9f97373f327b33734a6b85c58847222b7858f88/flamingo-stairs)에서 가져왔습니다. 원본 커밋은 `c9f97373f327b33734a6b85c58847222b7858f88`이며 MIT 저작권·허가문을 [licenses/FLAMING-GAMES-MIT.txt](licenses/FLAMING-GAMES-MIT.txt)에 보존했습니다.

이 버전은 게임명, 화면 구성, 하늘과 계단 색상, 사람 캐릭터, 준비 신호와 미리보기를 변경했습니다. 기존 프로젝트의 `../art/character-actions.png`를 공유하며 이 원화의 생성·참조 출처는 저장소의 `docs/PROVENANCE.md`에 기록되어 있습니다. 원본 플라밍고 그림은 표시하지 않습니다. 외부 라이브러리, CDN, 외부 음원 없이 실행됩니다.

## 검증

Node Canvas에 실제 캐릭터 원화를 불러와 화면을 렌더했습니다. 시작, 터치 오르기, 방향 전환, 30계단 진행, 제한시간 회복, 잘못된 방향의 추락, 최고 기록, 재시작과 시간초과를 확인했습니다. 미리보기는 4개 무작위 시드에서 각각 100초씩 실행해 120계단 도달과 반복, 저장·오디오 없음, 입력 차단 및 준비 메시지 한 번 전송을 확인했습니다. 실제 브라우저 UI 검수는 통합 과정에서 진행합니다.
